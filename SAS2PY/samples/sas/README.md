# SAS-to-Python Agentic Prototype Samples

Synthetic SAS programs for parser, supervisor, agent-routing and QC development.

01_data_engineering_merge_means.sas: DATA step, PROC SORT, MERGE, PROC MEANS, intermediate datasets.
02_data_engineering_complex.sas: multiple DATA steps, missing values, BY merge, conditional logic, PROC MEANS.
03_end_to_end_glmselect.sas: data preparation, merge, means, GLMSELECT LASSO and STEPWISE, model outputs.

These programs are synthetic and require corresponding input datasets to execute in SAS. They can still be used immediately for parsing and agent-classification tests.
